
# COMO USAR - APPS DE CLIENTES

1. Suba TODO o conteúdo desta pasta para 1 repositório no GitHub chamado 'clientes'
2. Ative GitHub Pages em Settings > Pages > Branch main
3. Seus links vão ficar:
   - seunome.github.io/clientes/marca-bolos/
   - seunome.github.io/clientes/modelo-em-branco/

PARA CRIAR NOVO CLIENTE:
1. No seu computador, duplique a pasta 'modelo-em-branco'
2. Renomeie para 'ana-unhas'
3. Edite o index.html dela: troque nome e WhatsApp
4. Suba de novo para o GitHub

Pronto! Novo app em 2 minutos.
